# Практическая работа № 4. Регрессионная модель

## Цель работы

Построить и интерпретировать модель линейной регрессии, оценить качество её предсказаний с помощью метрик MAE, RMSE и R², проверить мультиколлинеарность признаков и выбрать наиболее подходящий набор признаков.

## Используемые технологии

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Statsmodels
- Jupyter Notebook

## Датасет

В работе используется датасет `Student_Performance.csv`, содержащий информацию об учебной деятельности студентов.

Датасет включает **10 000 строк и 6 столбцов**.

### Описание признаков

| Признак | Описание |
|---|---|
| `Hours Studied` | Количество часов учёбы |
| `Previous Scores` | Предыдущие результаты |
| `Extracurricular Activities` | Участие во внеклассных мероприятиях |
| `Sleep Hours` | Количество часов сна |
| `Sample Question Papers Practiced` | Количество решённых пробных тестов |
| `Performance Index` | Показатель успеваемости студента |

Целевая переменная — `Performance Index`. Задача модели заключается в предсказании этого показателя на основе остальных признаков.

## Ход работы

### 1. Загрузка и изучение данных

С помощью Pandas был загружен датасет. Выполнен первичный анализ данных: просмотр первых строк, проверка размеров таблицы, типов данных, статистических характеристик и пропущенных значений.

### 2. Подготовка данных

Признаки были разделены на числовые и категориальные. Целевая переменная `Performance Index` была отделена от остальных данных.

Датасет разделён на обучающую и тестовую выборки в соотношении 80:20:

- Обучающая выборка — 8 000 строк.
- Тестовая выборка — 2 000 строк.

Для подготовки данных использованы:
- `SimpleImputer` — обработка пропущенных значений.
- `StandardScaler` — стандартизация числовых признаков.
- `OneHotEncoder` — кодирование категориальных признаков.
- `ColumnTransformer` и `Pipeline` — объединение этапов обработки и обучения модели.

### 3. Построение базовой модели

Обучена базовая модель линейной регрессии `LinearRegression` с использованием всех доступных признаков.

Для оценки качества предсказаний использованы следующие метрики:

- **MAE** — средняя абсолютная ошибка предсказания.
- **RMSE** — квадратный корень из средней квадратичной ошибки.
- **R²** — коэффициент детерминации, показывающий, насколько хорошо модель объясняет вариацию целевой переменной.

Результаты базовой модели:

| Метрика | Значение |
|---|---:|
| MAE | 1.6111 |
| RMSE | 2.0206 |
| R² | 0.9890 |

Полученные результаты показывают высокое качество модели: она объясняет около 98,90% вариации целевой переменной на тестовой выборке.

### 4. Проверка мультиколлинеарности

Для анализа взаимосвязей между числовыми признаками построена корреляционная матрица. Дополнительно рассчитан показатель VIF (Variance Inflation Factor).

Полученные значения VIF:

| Признак | VIF |
|---|---:|
| `Hours Studied` | 1.0005 |
| `Previous Scores` | 1.0003 |
| `Sleep Hours` | 1.0001 |
| `Sample Question Papers Practiced` | 1.0004 |

Все значения VIF близки к 1, что указывает на отсутствие существенной мультиколлинеарности между числовыми признаками.

### 5. Построение сокращённой модели

Для сравнения была построена вторая модель, в которой исключён признак `Sleep Hours`, поскольку его линейная корреляция с целевой переменной очень слабая.

Остальные признаки сохранены, включая `Extracurricular Activities`.

Результаты сокращённой модели:

| Метрика | Значение |
|---|---:|
| MAE | 1.7384 |
| RMSE | 2.1864 |
| R² | 0.9871 |

### 6. Сравнение моделей

| Модель | MAE | RMSE | R² |
|---|---:|---:|---:|
| Базовая | 1.6111 | 2.0206 | 0.9890 |
| Сокращённая | 1.7384 | 2.1864 | 0.9871 |

Базовая модель показала немного лучшие результаты по всем трём метрикам. После удаления `Sleep Hours` ошибки увеличились, а значение R² немного снизилось.

### 7. Анализ остатков

Для сокращённой модели построен график остатков, представляющих собой разность между реальными и предсказанными значениями.

Также построен график сравнения реальных и предсказанных значений.

Графики используются для оценки точности предсказаний и выявления возможных систематических закономерностей в ошибках модели.

## Вывод

В ходе практической работы была построена базовая модель линейной регрессии для предсказания успеваемости студентов. Качество модели оценено с помощью MAE, RMSE и R².

Базовая модель показала следующие результаты: MAE = 1.6111, RMSE = 2.0206 и R² = 0.9890. Проверка VIF не выявила существенной мультиколлинеарности между числовыми признаками.

После исключения признака `Sleep Hours` качество модели немного снизилось: MAE увеличилась до 1.7384, RMSE — до 2.1864, а R² снизился до 0.9871.

Таким образом, **базовая модель с полным набором признаков является предпочтительной**, поскольку демонстрирует более высокую точность предсказаний. При этом окончательный выбор модели должен учитывать не только метрики качества, но и интерпретируемость, простоту и назначение модели.
